# OutpainterForAspectRatio2

Пакетный outpaint изображений под заданное соотношение сторон на базе
рабочего плагина **krita-ai-diffusion** (`j:\AI_Image_Enchance\krita-ai-diffusion\`)
и его сервера ComfyUI с моделями FLUX.2 Klein 4B + LoRA outpaint от fal:

- `flux-2-klein-4b-fp8.safetensors` (базовая модель)
- `Qwen3-4B-Q4_K_M.gguf` (текстовый энкодер, через `CLIPLoaderGGUF`)
- `flux-2-klein-4B-outpaint-lora.safetensors` (LoRA outpainting, strength 1.1)
- `flux2-vae.safetensors`

Граф узлов повторяет режим **Expand** плагина: зелёная заливка `#00FF00`,
`DifferentialDiffusion`, `SetLatentNoiseMask`, `ReferenceLatent`,
`FluxGuidance` + `Flux2Scheduler`/euler.

## Требования

- Windows, NVIDIA GPU (проверено на RTX 4090 24 GB).
- Установленный сервер плагина (папка `ai_diffusion\server` с venv).
- В системе достаточно иметь `python` (Pillow и requests) — но скрипт сам
  использует `python.exe` из venv сервера, если он найден.

## Быстрый старт

1. Скопируйте `.env` и укажите `SRC_DIR` (папка с изображениями).
   При необходимости поменяйте `ASPECT_RATIO` (по умолчанию — экран).
2. Запустите `process_images.bat`.
3. Результаты появятся в папке `OUT_DIR` (по умолчанию `output\`).

Сервер ComfyUI запускается автоматически, если ещё не запущен
(проверка `GET /system_stats`, ожидание до 180 секунд).

## Настройки (.env)

|---|---|---|

| `OUT_DIR` | `output` | папка для результатов |
| `ASPECT_RATIO` | `screen` | `screen` / `16x9` / `4x3` / `1.7778` |
| `SCREEN_FALLBACK` | `1920,1080` | если разрешение экрана не определяется |
| `MAX_LONG_SIDE` | `2560` | максимум длинной стороны канвы |
| `MAX_PIXELS` | `6000000` | максимум пикселей канвы |
| `STEPS` | `50` | шаги сэмплинга (карточка LoRA: 50 шагов) |
| `CFG` | `4.0` | guidance (карточка LoRA: 4.0) |
| `LORA_STRENGTH` | `1.1` | сила LoRA (карточка LoRA: 1.1) |
| `SEED` | `-1` | `-1` = случайный сид на каждое изображение |
| `GROW` / `FEATHER` / `BLEND` | `16` / `8` / `25` | расширение, растушёвка маски, зона перехода (blend = `selection_blend` плагина) |
| `BORDER_MAX_RATIO` | `0.25` | макс. доля рамки от меньшей стороны (порог многопроходности) |

| `PASS_BORDER_RATIO` | `0.25` | макс. доля рамки одного прохода от текущей меньшей стороны |
| `SKIP_IF_MATCH` | `true` | пропускать, если соотношение уже совпадает |
| `COLOR_MATCH` | `true` | согласование цветов с оригиналом (как в плагине по умолчанию) |
| `RESUME` | `true` | продолжать с места остановки |
| `PROMPT` | `Fill the green spaces according to the image.` | промпт |

| `SERVER_URL` | `127.0.0.1:8188` | адрес ComfyUI |

## Правило расширения сторон

- Целевое соотношение **шире** исходного → расширяются **левая и правая** стороны.
- Целевое соотношение **выше** исходного → расширяются **верхняя и нижняя** стороны.
- Расширяются только две стороны, не четыре. Рамка делится поровну.

## Параметры командной строки

```
run_outpaint.py [--env .env] [--src DIR] [--out DIR] [--ratio 16x9]
                [--steps N] [--cfg F] [--seed N] [--limit N] [--only STR]
                [--resume | --no-resume] [--dry-run] [--check]
```

- `--dry-run` — не отправляет задание, а сохраняет JSON графа в `output\debug\`.
- `--check` — только проверка сервера, узлов и моделей, затем выход.

## Как это работает

1. Читается `.env`, вычисляется целевое соотношение (экран или явное).
2. Для каждого изображения строится канва: оригинал по центру, рамка — чистый
   зелёный `#00FF00`; маска белая в области рамки.
3. Изображения загружаются в кэш ComfyUI (`PUT /api/etn/image/{id}`).
4. Отправляется граф (`POST /prompt`), результат ожидается через
   `GET /history/{prompt_id}` (без WebSocket). Параметры: 50 шагов,
   CFG 4.0, LoRA 1.1, `INPAINT_ColorMatch` включён.
5. **Композит как в плагине**: сначала канва обрезается до точного целевого
   размера (crop), затем сгенерированная рамка накладывается на точный
   оригинал с альфа-маской `ThresholdMask(0.0) → ShrinkMask(blend//2, blend)`,
   переход уходит в сторону дорисованной области — зелёный шов по краю
   исчезает. Оригинал в центре остаётся побитово точным.
6. **Пост-очистка шума**: только на дорисованной области применяется
   медианный фильтр (3×3), оригинал не затрагивается.
7. **Один проход по умолчанию** (`MULTI_PASS=false`): вся рамка дорисовывается
   за один проход. Многопроходность (`MULTI_PASS=true`) оставляет тёмные
   полосы-тени на границах каждого прохода (по несколько на сторону), поэтому
   выключена. Включайте только при необходимости контролировать шум на очень
   больших рамках и если полосы на стыках проходов допустимы.
8. Ожидаемое время ~2–3 минуты на фото 4:5 → 16:9 (50 шагов,
   (поддержка `--resume`).
8. Ожидаемое время ~2–3 минуты на фото 4:5 → 16:9 (50 шагов × 3 прохода).

## Возможные проблемы

- **Prompt rejected / Missing nodes** — проверьте, что сервер обновлён и
  установлены custom nodes (comfyui-tooling-nodes, comfyui-inpaint-nodes,
  ComfyUI-GGUF). Для `COLOR_MATCH` нужна нода `INPAINT_ColorMatch`
  (comfyui-inpaint-nodes); скрипт проверяет её наличие при запуске.
- **OOM на больших разрешениях** — уменьшите `MAX_LONG_SIDE` / `MAX_PIXELS`
  или количество шагов.
- **Версия пайплайна** — код хранит `PIPE_VERSION` (`v3`); при изменении
  логики обработки поднимите его, чтобы `--resume` пересчитал старые
  результаты (ключ манифеста включает версию).
